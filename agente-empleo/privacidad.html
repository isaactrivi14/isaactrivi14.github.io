Política de privacidad

Última actualización: 26 de octubre de 2026

El Agente de empleo es una aplicación personal desarrollada y usada únicamente por Isaac David Triviño Ruiz («el propietario»). No ofrece cuentas a otras personas.

Datos a los que accede

  • Gmail (lectura): correos de empresas y de portales de empleo relacionados con los procesos de selección del propietario.
  • Gmail (envío): envía únicamente las respuestas y postulaciones que el propietario aprueba de forma explícita.
  • Google Calendar (eventos): crea eventos para las entrevistas de trabajo del propietario.

Cómo se usan y se guardan

Los datos se usan solo para clasificar respuestas de empresas, detectar entrevistas, redactar borradores y crear recordatorios. Se guardan en una base de datos privada del propietario, protegida con autenticación y seguridad por filas, a la que solo él tiene acceso.

Con quién se comparten

Con nadie. Los datos no se venden, no se ceden a terceros y no se usan para publicidad ni para entrenar modelos de inteligencia artificial.

El uso que hace esta aplicación de la información recibida de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Eliminación

El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions y borrar los datos guardados en su base de datos.
